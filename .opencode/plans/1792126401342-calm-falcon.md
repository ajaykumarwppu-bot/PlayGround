# Final Plan: "Complete Any Chapter in 5 Steps" — Paper-Cutout Vox-Style YouTube Short (Remotion)

## Goal & confirmed decisions

Render a finished vertical Short from the user's Hinglish script using Remotion:

- **Format:** 1080x1920 (9:16), 30 fps, target ~110-120 s, hard cap 3:00 (5400 frames)
- **Voice:** Hindi male TTS — edge-tts `hi-IN-MadhurNeural`, rate +35% (energetic), Devanagari with Latin English loanwords for natural Hinglish
- **Captions:** Roman Hinglish word-by-word karaoke (script ke jaise), Anton font, pop-in + active-word highlight
- **Audio:** VO + SFX (synthesized) + ducked background music (CC BY, credited)
- **Style:** Vox-style flat paper cutout, 2.5D parallax (4-6 depth layers), stop-motion "paper boil" jitter every 2-3 frames, fast pacing (new paper beat every ~0.8-1.5 s), scissors-wipe transitions
- **Assets:** textures/edges procedural (SVG + generated grain PNG); music from internet (Incompetech, verified 200); fonts from google/fonts raw (OFL, verified 200); SFX synthesized in pure Node (no licensing risk)

## Environment facts (verified)

- Node v22.23.3 / npm 10.9.9; no pnpm/bun
- Chrome 155 at `/usr/bin/google-chrome` → Remotion flags `--browser-executable=/usr/bin/google-chrome --chrome-mode=chrome-for-testing --gl=swangle`
- No system ffmpeg → use bundled `npx remotion ffmpeg` / `ffprobe`
- edge-tts 7.3.1 on PyPI; install via `python3 -m venv .venv-tts` (PEP-668-safe). `hi-IN-MadhurNeural` GA
- Music sources: Incompetech direct MP3 = 200 (CC BY, attribution required); Pixabay/Mixkit CDN = 403 from this network (rejected)
- Repo is greenfield; platform serves root `index.html` only → Remotion in `remotion/` subfolder, root index.html stays the served app
- Remotion latest 4.0.535; React 19.0.0; 4 cores → budget ~15-35 min final render

## Execution phases (approx 2.5-3.5 h total)

1. **Scaffold (20 min):** write package.json/config/tsconfig, `npm install`, seed timing, minimal Root + ChapterVideo; smoke test `npx remotion compositions` + `still --frame=0` → Read image.
2. **Assets (20 min):** download fonts + OFL.txt (github raw), music `Carefree.mp3` from Incompetech (fallback "Life of Riley"; write CREDITS.txt + attribution in video end card & page footer); venv + `pip install edge-tts==7.3.1`; run `generate_assets.mjs`; ffprobe spot-checks.
3. **Content + VO (30 min):** author `content/script.json` (dual-script lines + display tokens + SFX cues); run TTS; `check:duration` ≤5400 (retune rate/gaps once if >170 s, trim proprietary lines only if needed — all 5 steps always kept).
4. **Visual system + scenes (60-90 min, bulk):** implement paper components, captions, audio layers, 10 scenes; iterate via `remotion still` at ~12 key frames, Read each.
5. **Draft render (20 min):** `render:draft` (scale 0.5), ffprobe duration/streams, extract frames at 2 fps, fix issues; per-scene `--frames=a-b` checks.
6. **Final render + validation (~25-40 min):** full `npm run render` → `media/chapter-5-steps.mp4`; ffprobe + full-decode + size + RMS/peak audio check; poster still.
7. **Player page:** upgrade root `index.html` (paper-cutout styled, relative paths only): video player, chapter chips (currentTime jumps), download button, 5-step recap, attribution footer.

## Verification

- `npx remotion compositions` → correct id/size/fps/duration
- ~12 stills Read & inspected (no clipping, captions in safe band, fonts loaded, torn edges render)
- Draft + clip renders → pacing/sync review, no black frames, captions during speech
- Final: ffprobe (h264 1080x1920 30 fps, aac 48k, ≤180 s), full decode no errors, <100 MB, audio RMS -22..-13 dBFS, peak < -0.5
- Serve via `./start.sh` (port 3002, tmux) + `playwright-cli screenshot` of player page → Read screenshot
- Known limitation: TTS audio can't be listened to in CI — cue/text alignment assertions + RMS checks; human listen pass recommended

## Risks & mitigations

- VO > 3:00 → rate +35→+40%, gaps 8→6 frames, hard gate in check_duration, trim order: bonus → problem beat, never steps
- edge-tts flake → 6x exponential backoff per segment, pinned version, fallback voices (Swara, Prabhat)
- Chrome 155 in CI → verified headless launch; fallback: no-sandbox wrapper script, then Remotion bundled Headless Shell (storage.googleapis.com reachable)
- 4-core render time → draft-first workflow, concurrency 4, JPEG frames
- Music license → CC BY attribution in 3 places (index.html, CREDITS.txt, end card); if track download fails → Pixabay partial URLs unusable, ship VO+SFX bed intentionally reduced volume or re-check alternates
